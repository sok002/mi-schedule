# جدولي الأسبوعي — Medical Informatics Program

تطبيق ويب بسيط لطلاب **برنامج المعلوماتية الطبية الذكية** (كلية الحاسبات والذكاء الاصطناعي — جامعة بنها) لعمل جدول المحاضرات والسكاشن الأسبوعي وتصديره **PDF**.

## المميزات
- كتابة الاسم واختيار المستوى، ثم اختيار المواد (مع إمكانية إضافة مواد من مستويات أخرى).
- مواد البرنامج الموجودة في جدولي **أمن المعلومات** و**الشبكات** (التصميم المنطقي، الكتابة التقنية، الجبر الخطي) مع اختيار مجموعة السكشن.
- تعديل أي موعد تغير بالاتفاق مع الدكتور/المعيد: اختيار اليوم وفترة أو حتى 3 فترات متتالية، ومكان جديد اختياري.
- تنبيه عند وجود تعارض في المواعيد.
- تصدير PDF بنفس تنسيق «الجدول الأسبوعي» (A4 بالعرض)، أو طباعة مباشرة.
- يحفظ اختياراتك في المتصفح لتكمل لاحقا.
